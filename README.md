# Weather Dashboard

Real-time weather dashboard with 5-day forecast and city autocomplete.

## Features
- Search any city with autocomplete suggestions
- Current conditions: temperature, humidity, wind speed, feels like, visibility
- 5-day forecast with daily highs/lows
- Dark/Light mode toggle (persists across sessions)
- Fully responsive design

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- OpenWeatherMap API (current weather + 5-day forecast + geocoding)
- FontAwesome icons
- LocalStorage for theme persistence

## How to Run Locally
1. Clone the repository
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
3. Replace `YOUR_API_KEY_HERE` in `script.js`
4. Open `index.html` in your browser
